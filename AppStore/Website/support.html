Pair with Tubeist

Use an iPhone or iPad running iOS or iPadOS 18 or later for Scorer. A second iPhone runs Tubeist 2.4.0 or later for recording or streaming.

  1. In Tubeist, open Settings → Overlays → Nearby Overlay. You can also touch and hold Overlays on the camera screen and choose Nearby Overlay.
  2. Tap Start receiving. In Scorer, tap the Bluetooth control in the top-left corner and enter the six-digit code shown in Tubeist.
  3. Select the nearby Tubeist device and accept the system Bluetooth pairing prompt if it appears.
  4. When Scorer says Connected to Tubeist, tap Done on both devices and return to the Tubeist camera.

Troubleshoot Bluetooth

Scorer is still looking for Tubeist

Bring the devices closer and keep both apps open. Check that Bluetooth is on and both apps have Bluetooth permission. In Tubeist, open Nearby Overlay and tap Refresh discovery if shown. Then select Tubeist from Scorer.

Scorer lost the connection

Tubeist holds the latest graphic while Scorer tries to reconnect. Bring the devices closer and return Scorer to the foreground. Scorer sends the current match state when it reconnects.

Tubeist asks for a new pairing code

Open Nearby Overlay in Tubeist and tap New pairing code if the receiver is already paired. Enter the new code in Scorer and choose Tubeist again.

How do I take the graphic off the video?

In Tubeist’s Nearby Overlay panel, tap Remove overlay. Use Stop receiving to end the Bluetooth session. If you only stop receiving, the latest graphic stays on the video until you remove it.

Scoring and graphics

Choose a Sport above the preview. Tap the percentage beside Overlay preview to change the overlay size. The app saves your teams, score, theme, and scale for each sport.

For doubles, you can enter both names in one field, for example Andersson / Nilsson. Pickleball also has a Doubles mode that tracks the serving side and server number.

Contact support

Email support@uptochange.com. Include both device models, the iOS or iPadOS versions, the app versions, and the Bluetooth status shown on each device.
